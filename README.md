# file-manager
File Manager Plugin for WardokCMS

### What's New in v1.2.0:
1. **Subfolder Management**: Create, browse, rename, and organize nested folders (e.g. `uploads/2026/`, `uploads/covers/`).
2. **Interactive Breadcrumb Navigation**: Jump back to any parent folder with one click (`Uploads / 2026 / August`).
3. **Smart Autoindexing**: Automatically categorizes folders and file types with badges, dimensions, and file sizes.
4. **File & Folder Operations**:
   * Multi-file drag & drop uploads into the **current active folder**.
   * One-click **Copy URL** (full direct URL).
   * **Rename** any file or folder.
   * **Delete** files or folders safely.
5. **Instant Live Search Filter**: Filter files and folders in real time as you type.
